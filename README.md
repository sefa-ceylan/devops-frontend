# DevOps Frontend

Market satış dashboard'u — backend API'den veri çekip gösteren Next.js uygulaması.

## Teknolojiler
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Recharts

## Local'de çalıştırma
```bash
npm install
npm run dev
```
`http://localhost:3000` adresinde açılır.
